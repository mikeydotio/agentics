## Key facts

- Claude Code plugin marketplace; marketplace.json is the sole plugin registry.
- 11 plugins live under plugins/<name>/, each with its own bin/, skills/, references/.
- Skills are thin routers; bin/ scripts (bash+jq or stdlib python3) do deterministic work.
- plugins/agents/agents/ is the shared specialist library forge/rca/atlas/council spawn from.
- Consumers inline a shared agent file plus their own agent-overrides/<name>-context.md.
- State = artifact dirs: .forge/ .rca/<slug>/ .atlas/ .semver/ .freshen/; presence drives resume.
- semver's post-bump hook one-way-stamps VERSION into every plugin.json and marketplace.json.
- freshen queues a signal file; its hooks tmux-send /clear + re-invocation, pane-confirmed.
- hook-guard is a shared circuit breaker any plugin's Stop hook sources to halt runaway loops.
- greenlight is a PreToolUse hook gating Bash calls: deterministic allow/warn plus AI fallback.
- Atlas v2 separates deterministic extraction/projection from LLM judgment cells.
- forge's step-exit protocol (artifact, commit, queue freshen, STOP) is uniform across all steps.
- Plugins share no runtime code except the shared agent library, semver stamp, and freshen signals.
- make test aggregates semver, deployit, atlas, and root bats suites; a pre-push hook runs it.
